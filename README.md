## About Me

I am a **QA Automation Engineer** focused on building reliable, maintainable and scalable test automation that lets engineering teams ship faster with confidence. I treat test code as production code — designed with clean architecture, reusable abstractions, version control discipline and CI-first execution.

My core strength is **end-to-end automation engineering** across UI and API layers using **Playwright, Selenium WebDriver and TestNG**, backed by Page Object Model, data-driven and hybrid framework design. I build frameworks that run in parallel, report clearly, fail meaningfully and integrate directly into CI/CD pipelines.

Beyond functional automation, I work on **AI-assisted testing and workflow automation** — using LLM agents and **n8n** to generate test data, triage failures, summarize reports and automate repetitive QA operations. I also build full-stack side projects (Flutter, Supabase, web ERP) so I understand the systems I test from the inside out.

I approach quality with a **product engineering mindset**: understand the user, map the risk, automate what matters, and measure quality through coverage, stability and release confidence — not just test counts.

**Open To**

- QA Automation Engineer / SDET roles
- Test framework design and automation architecture
- AI-assisted testing and QA tooling initiatives
- Freelance automation and workflow projects
- Open-source testing tools and collaboration
